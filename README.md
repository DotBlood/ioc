# IOC — Stateful Knowledge Graph Runtime

**IOC** (Input Output Context) — runtime-инфраструктура для организации исследовательских работ с использованием knowledge graph как основы памяти проекта.

---

## 🏗️ Архитектура

IOC объединяет три ключевых слоя:

### 1. Knowledge Graph — статическая память проекта

Граф как модель данных, хранящая жесткие факты и связи. Физически реализуется через графовую базу данных.

**Уровни иерархии:**

| Уровень       | Назначение                                  |
| ------------- | ------------------------------------------- |
| **Worktree**  | Корневой проект — общая статическая память  |
| **Workspace** | Область изучения/работы — цель исследования |
| **Session**   | Конкретная задача/scope в рамках workspace  |
| **Artifact**  | Файлы, Q&A, результаты, выводы исследования |

### 2. Stateful — динамическая память проекта

Динамическая память, которая постоянно перезаписывается в процессе работы:

| Уровень               | Назначение                                   | Аналогия             |
| --------------------- | -------------------------------------------- | -------------------- |
| **Worktree Stateful** | Глобальная память проекта (долгосрочная)     | Долгосрочная память  |
| **Scope Stateful**    | Локальная память scope (Workspace + Session) | Краткосрочная память |

**Stateful хранит:** пометки, статусы, историю взаимодействий, временные метки.

### 3. Runtime — двигатель выполнения

MCP/API-инфраструктура, связывающая graph с LLM:

- **Graph Traversal** — поиск по графу по запросу LLM
- **Context Assembly** — сборка релевантного контекста
- **Response Formatting** — форматирование ответов
- **State Updates** — запись изменений обратно в граф

## 📐 Иерархия данных

```
Worktree IOC
└── Worktree Stateful — глобальные выводы, ссылки на scope/artifacts
    │
    ├── Workspace 1
    │   ├── Workspace Stateful — локальный контекст
    │   │   └── Session 1
    │   │       ├── Session Stateful
    │   │       │   ├── Artifact 1
    │   │       │   └── Artifact 2
    │   │       └── Session 2
    │   └── Workspace Summarize — резюме всех Sessions
    │
    └── Workspace 2
        └── ...
```

## 🎯 Ключевые принципы

### Изоляция контекста

Главная особенность IOC — **ограничение контекста** между разными сервисами и AI-агентами:

- ❌ Не смешиваем контексты разных workspace
- ✅ Каждый scope имеет свою изолированную память
- ✅ Избегание перегрузки AI избыточным контекстом

### Мутация stateful

- **Worktree Stateful** — менее мутабельна (глобальная согласованность)
- **Scope Stateful** — более мутабельна (быстрое ориентирование)
